# Shared assets

Canonical binary assets used across Ross Floate Things belong here.

## Imprimatur

The approved maker mark is the **circular Ross portrait + “A Ross Floate Thing”** as one indivisible mark of authorship.

The canonical portrait source is `ross-floate-imprimatur-portrait.png`. Use this
exact file; do **not** redraw it, reinterpret it or generate a substitute. Native
apps may apply a circular presentation mask without altering the source artwork.

No RF signature, monogram, alternate maker logo or secondary authorship mark is part of the system.
