# References

## Reference Board 001 — initial Ross Floate Things direction

**Status:** Approved baseline, with later corrections documented in `DESIGN-SYSTEM.md`.

This is the first visual direction board developed for the app family. It established the dark compact Mac-utility direction, safety-orange attention language, visible progress/machinery, restrained whimsy, native control sensibility, dialogs/states, result presentation and initial component vocabulary.

The original board should be stored here as `reference-board-001.png` when the exact binary asset is available to the repository workflow. Do not recreate or AI-regenerate it merely to fill the slot; preserve the approved original.

Later decisions supersede two details visible on the board:

1. The canonical display orange starts from Good Internetting **#FF5A00**, rather than the board's provisional #FF8A00.
2. The RF signature shown at the lower right is **not** part of the system. The sole authorship mark is the circular Ross portrait + **A Ross Floate Thing** imprimatur.

The board's other baseline choices are treated as provisionally accepted and should be tested/refined through NameThese rather than redesigned from scratch.
